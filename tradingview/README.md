# 3分足デイトレ 売買タイミングインジケーター

TradingView用のPine Script(v5)インジケーターです。3分足でのデイトレードを想定し、
以下の条件が揃った足で「買い」「売り」の矢印シグナルを表示します。

## シグナルロジック

| フィルター | 内容 |
|---|---|
| EMAクロス | EMA9とEMA21のゴールデンクロス/デッドクロスをトリガーにする |
| VWAP | 価格がVWAPより上のときのみ買い、下のときのみ売りを採用(トレンド方向の逆張りを避ける) |
| RSI | RSIが買われすぎ(既定70)/売られすぎ(既定30)のときは新規エントリーを見送る |
| 出来高 | 直近平均出来高に対して一定倍率以上あるときのみシグナルを採用(閑散相場のダマシ回避) |
| 上位足トレンド | 既定15分足のEMA9/21が上向きのときのみ買い、下向きのときのみ売りを採用(逆行シグナルの除外) |

各フィルターは個別にON/OFFでき、時間帯を絞る「取引時間帯フィルター」も任意で使えます。
上位足トレンドフィルターを有効にすると、チャート右上に現在の上位足トレンド(上昇/下降/横ばい)が
色付きで常時表示されます。上位足の時間足やEMA期間はパラメータから変更可能です
(3分足チャートの場合、上位足には5分より大きい足を選んでください。選択した足が現在のチャート足以下だと
右上に赤色で「上位足設定エラー」と表示されます)。

## 導入方法

1. TradingViewを開き、対象銘柄のチャートを3分足に設定する
2. 画面上部の「Pine Editor」を開く
3. `3min-scalping-indicator.pine` の中身を貼り付けて保存
4. 「チャートに追加」でインジケーターを表示
5. インジケーターの歯車アイコンからパラメータ(EMA期間、RSI水準、出来高倍率など)を調整
6. 矢印(▲買い / ▼売り)が出た足でアラートを鳴らしたい場合は、インジケーター上で右クリック→
   「アラートを追加」→ 条件で「買いシグナル発生」または「売りシグナル発生」を選択

## 注意事項

- 本インジケーターは売買を自動で行うものではなく、あくまで判断材料の一つです。
- 上位足トレンドフィルターは`request.security()`で取得した上位足の未確定足(現在形成中の足)を参照するため、
  リペイント(上位足が確定するまで表示が変わりうる)する場合があります。厳密なバックテストを行う場合は
  この点に留意してください。
- パラメータ(EMA期間・RSI水準・出来高倍率・上位足時間軸)は銘柄のボラティリティに応じて調整してください。
