# 3分足デイトレ 売買タイミングインジケーター

TradingView用のPine Script(v5)インジケーターです。3分足でのデイトレードを想定し、
条件が揃った足で「買い」「売り」の矢印シグナルを表示します。

## シグナルロジック

EMAクロスをシグナルの起点とし、そこに以下4つの補助条件のうち「いくつクリアしているか」を
スコアとして数えます(AND必須ではなくスコア制)。

| 起点/補助条件 | 内容 |
|---|---|
| EMAクロス(起点) | EMA9とEMA21のゴールデンクロス/デッドクロスが発生した足のみ候補にする |
| VWAP | 価格がVWAPより上のときのみ買い、下のときのみ売りでスコア加点(トレンド方向の逆張りを避ける) |
| RSI | RSIが買われすぎ(既定70)/売られすぎ(既定30)でないときにスコア加点 |
| 出来高 | 直近平均出来高に対して一定倍率以上あるときにスコア加点(閑散相場のダマシ回避) |
| 上位足トレンド | 既定15分足のEMA9/21のトレンド方向と一致するときにスコア加点 |

「シグナルの厳しさ」グループの**採用に必要な条件数**(既定3/4)で、上記4条件のうちいくつクリアすれば
確定シグナル(▲買/▼売、太い矢印+アラート対象)にするかを調整できます。

- **4に設定** = 全条件必須。だましは最少になりますが、上位足の反応が遅れる分シグナル自体が減り、
  早い転換タイミングを逃しやすくなります。
- **0〜2に設定** = EMAクロスだけ、または一部の条件でシグナルを出すため機会損失は減りますが、
  だましも増えます。
- 個別のフィルターをOFFにすると、そのフィルターは自動的に「クリア済み」扱いになりスコアに1加算されます
  (実質的にそのフィルターを条件から除外するのと同じ効果です)。

しきい値未満でEMAクロスだけ発生した足は、「参考シグナル(EMAクロスのみ・未確認)を薄く表示する」を
ONにしておくと小さく薄いマークで表示されます。「本命シグナルは見送るが、早めの動きとして意識しておきたい」
というタイミングを見逃さないための表示で、こちらはアラート対象にはなりません。

上位足トレンドフィルターを有効にすると、チャート右上に現在の上位足トレンド(上昇/下降/横ばい)が
色付きで常時表示されます。上位足の時間足やEMA期間はパラメータから変更可能です
(3分足チャートの場合、上位足には5分より大きい足を選んでください。選択した足が現在のチャート足以下だと
右上に赤色で「上位足設定エラー」と表示されます)。

## 導入方法

1. TradingViewを開き、対象銘柄のチャートを3分足に設定する
2. 画面上部の「Pine Editor」を開く
3. `3min-scalping-indicator.pine` の中身を貼り付けて保存
4. 「チャートに追加」でインジケーターを表示
5. インジケーターの歯車アイコンからパラメータ(EMA期間、RSI水準、出来高倍率、必要条件数など)を調整
6. 矢印(▲買い / ▼売り)が出た足でアラートを鳴らしたい場合は、インジケーター上で右クリック→
   「アラートを追加」→ 条件で「買いシグナル発生」または「売りシグナル発生」を選択

## 注意事項

- 本インジケーターは売買を自動で行うものではなく、あくまで判断材料の一つです。
- 上位足トレンドフィルターは`request.security()`で取得した上位足の未確定足(現在形成中の足)を参照するため、
  リペイント(上位足が確定するまで表示が変わりうる)する場合があります。厳密なバックテストを行う場合は
  この点に留意してください。
- パラメータ(EMA期間・RSI水準・出来高倍率・上位足時間軸)は銘柄のボラティリティに応じて調整してください。
- 投資判断は自己責任で行ってください。
