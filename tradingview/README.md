# 3分足デイトレ 節目+ローソク足シグナル

TradingView用のPine Script(v5)インジケーターです。3分足でのデイトレードを想定し、
**節目(サポート/レジスタンス)とローソク足の反転パターン**だけで売買タイミングを表示します。
移動平均線やオシレーターは使いません。

## シグナルロジック

1. 直近のピボット高値・安値を「節目」として自動検出し、サポート/レジスタンスの水平線(点線)を
   チャートに描画する(サポート/レジスタンスそれぞれ直近1本ずつ)
2. ローソク足が節目付近(ATRの倍率で判定、既定0.5倍)まで接近しているかを判定する
3. その足が反転パターンに該当していれば、サポート付近なら買い、レジスタンス付近なら売りとして
   ▲買/▼売を表示する

ただし、節目とパターンが揃っただけでは「まだ下降トレンドが続いている最中に買ってしまう」
「ナイフ落とし」を防げません。そこで**トレンド構造フィルター**(既定ON)を併用しています。

- 買いシグナル: 直近のピボット安値が、その1つ前のピボット安値より**高い**(切り上げ安値)場合のみ採用
- 売りシグナル: 直近のピボット高値が、その1つ前のピボット高値より**低い**(切り下げ高値)場合のみ採用

つまり、安値を切り下げ続けている(下降の勢いが続いている)間の買いや、高値を切り上げ続けている間の
売りは自動的に除外されます。OFFにすると、この構造チェックなしで節目+パターンだけの判定に戻ります
(シグナル数は増えますが、トレンド継続中の逆張りエントリーも増えます)。

ただし、この切り上げ安値/切り下げ高値の判定は**直前のピボット1つとの比較**でしかないため、
大きな下降トレンドの中の小さなレンジ相場でも「ニセの切り上げ安値」を拾ってしまうことがあります。
これを補うため、**背景トレンドフィルター**(既定ON)も併用しています。より長い期間のEMA(既定50本)
に対して、買いは終値がその上にあるとき、売りは下にあるときだけ採用します。このEMAはチャートには
表示されません(「背景トレンドのラインを表示する」をONにすれば薄いグレーの線として確認できます)。
大きな流れに逆らうシグナルを避けるための裏方のフィルターという位置づけです。

| パターン | 内容 |
|---|---|
| 包み足(エンゲルフィング) | 前の足の実体を完全に飲み込む陽線/陰線 |
| ピンバー/ハンマー(買い) | 下ヒゲが実体に対して長く(既定: レンジの60%以上)、上ヒゲが小さい形 |
| 流れ星(売り) | 上ヒゲが長く、下ヒゲが小さい形 |

出来高フィルター(直近平均出来高の一定倍率以上)も任意で適用できます。

## トレードプラン(損切り/利確ライン)

ここまでのフィルターを重ねても「当たるシグナルだけ」にはなりません。価格アクションの性質上、
教科書通りの正しい形のセットアップでも普通に外れます。そのため本インジケーターは**シグナルの
的中率を上げることを目指していません**。代わりに、シグナル発生時に次の2本の点線を同時に表示し、
「当たったら何倍獲れて、外れたら何を失うか」を事前に見えるようにしています。

- **損切りライン(赤)**: 買いなら節目(サポート)のすぐ下、売りなら節目(レジスタンス)のすぐ上。
  節目が壊れたらそこで撤退する、というライン
- **利確ライン(青)**: 買いなら次の直近レジスタンス、売りなら次の直近サポート。使える節目がない
  場合は、既定でリスク(損切りまでの値幅)の1.5倍の位置を目安として表示
- ラベルに損切り価格・利確価格・リスクリワード比率(RR)を表示

表示されるのは直近の買い/売りそれぞれ1件分のプランのみで、新しいシグナルが出ると前のものと
置き換わります(「損切り/利確ラインを表示する」でON/OFF可能)。

## 設定項目

- **節目確定に使う左右の本数(ピボット感度)**: 小さいほど細かい節目を多く拾う(だまし増)、
  大きいほど大きな節目だけを拾う(反応は遅れる)
- **節目と見なす近さ(ATRの倍率)**: 値が大きいほど「節目付近」の判定が緩くなり、シグナルが増える
- **節目のラインをチャートに表示する**: サポート/レジスタンスの点線表示のON/OFF
- **包み足/ピンバーパターンを使う**: 各パターンの個別ON/OFF
- **ピンバーの実体に対するヒゲの最低割合**: ピンバー判定の厳しさ
- **出来高フィルター**: 閑散相場でのだましを減らす任意フィルター
- **トレンド構造フィルター**: 切り上げ安値/切り下げ高値のときだけシグナルを採用する(既定ON、推奨)
- **背景トレンドフィルター**: より長い期間のEMA(既定50本)に逆らわないシグナルだけ採用する(既定ON、推奨)
- **背景トレンド判定の期間(EMA)**: 上記EMAの期間。長くするほど大きな流れ、短くするほど中期的な流れを見る
- **背景トレンドのラインを表示する**: 通常は非表示。判定に使っているEMAを確認したいときだけON
- **損切り/利確ラインを表示する**: トレードプラン(SL/TP)の表示ON/OFF(既定ON)
- **次の節目が使えない場合の利確目標**: 使える節目がない時の目標をリスクの何倍にするか(既定1.5倍)
- **損切り/利確ラインを右に伸ばす本数**: プランのラインをチャート上に何本分表示するか

ピボット判定の性質上、節目が確定するまで(左右の本数分)ラグがあります。これは「本当にその
高値/安値で反応したか」を確認してから節目として採用するための遅れで、パターン自体の検出は
リアルタイムです。

## 導入方法

1. TradingViewを開き、対象銘柄のチャートを3分足に設定する
2. 画面上部の「Pine Editor」を開く
3. 中身を全て削除してから `3min-scalping-indicator.pine` の内容を貼り付けて保存する
   (前のコードが残ったまま貼り足すとエラーの原因になります)
4. 「チャートに追加」でインジケーターを表示する
5. 歯車アイコンから各パラメータを調整する
6. シグナルが出た足でアラートを鳴らしたい場合は、インジケーター上で右クリック→
   「アラートを追加」→ 条件で「買いシグナル発生」または「売りシグナル発生」を選択

## 注意事項

- 本インジケーターは売買を自動で行うものではなく、あくまで判断材料の一つです。
- サポート/レジスタンスは直近1本ずつのみ保持するシンプルな構成です。もっと古い節目も見たい場合は
  手動でラインを引くか、別途ラインツールと併用してください。
- パラメータ(ピボット感度・ATR倍率・出来高倍率など)は銘柄のボラティリティに応じて調整してください。
- 投資判断は自己責任で行ってください。
