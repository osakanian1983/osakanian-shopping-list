# 3分足デイトレ 売買タイミングインジケーター

TradingView用のPine Script(v5)インジケーターです。3分足でのデイトレードを想定し、
条件が揃った足で「買い」「売り」のシグナルを表示します。

## シグナル方式の切り替え(最重要設定)

「シグナル方式(切り替え)」グループの**表示するシグナル方式**で、2つの方式を切り替えられます。
どちらも内部の計算は常に行われているので、いつでも即座に切り替えて比較できます。

### A) 反発型(トレンド一致フィルター) [既定]

ストキャスティクス(%K/%D)が売られすぎ/買われすぎ圏で交差した時点を「反発シグナル」(ひし形)として
表示します。EMAクロスを待たないため、底値圏・天井圏でのより早いタイミングを拾えます。

さらに、上位足(既定15分足)のトレンド方向と一致するかどうかで表示を分けます。

| 状態 | 例 | 表示 |
|---|---|---|
| 順張り(トレンド一致) | 上昇トレンド中の押し目買い、下降トレンド中の戻り売り | 濃い色・太字ラベルで表示(信頼度が高い) |
| 逆行(トレンドに逆らう) | 上昇トレンド中の戻り売り、下降トレンド中の押し目買い | 薄く小さい表示(新規エントリーの根拠にはせず、利確や警戒の参考程度に) |

「反発型: トレンドに逆行するシグナルを非表示にする」をONにすると、逆行分は完全に非表示にできます。

### B) EMAクロス型(スコア制)

EMA9/21のゴールデンクロス/デッドクロスを起点とし、そこにVWAP・RSI・出来高・上位足トレンドの
4条件のうち「いくつクリアしているか」をスコアとして数えます(AND必須ではなくスコア制)。

| 起点/補助条件 | 内容 |
|---|---|
| EMAクロス(起点) | EMA9とEMA21のゴールデンクロス/デッドクロスが発生した足のみ候補にする |
| VWAP | 価格がVWAPより上のときのみ買い、下のときのみ売りでスコア加点 |
| RSI | RSIが買われすぎ(既定70)/売られすぎ(既定30)でないときにスコア加点 |
| 出来高 | 直近平均出来高に対して一定倍率以上あるときにスコア加点 |
| 上位足トレンド | 既定15分足のEMA9/21のトレンド方向と一致するときにスコア加点 |

「シグナルの厳しさ」グループの**採用に必要な条件数**(既定3/4)で、しきい値を調整できます。

- **4に設定** = 全条件必須。だましは最少になりますが、上位足の反応が遅れる分シグナル自体が減り、
  早い転換タイミングを逃しやすくなります。
- **0〜2に設定** = 機会損失は減りますが、だましも増えます。
- 個別のフィルターをOFFにすると、そのフィルターは自動的に「クリア済み」扱いになりスコアに1加算されます。
- しきい値未満でもEMAクロス自体は発生していれば、「参考シグナル(EMAクロスのみ・未確認)を薄く表示する」で
  小さく薄いマークとして表示できます(アラート対象外)。
- このモードはEMAクロス起点のため、反発型より反応がやや遅くなる傾向があります。

### どちらを使うか

まず反発型(既定)で運用し、シグナルが合わない・使いにくいと感じたら「表示するシグナル方式」を
EMAクロス型に切り替えて比較してください。反発型は早いタイミングを拾いやすい代わりにシグナル数が
多くなりがちで、EMAクロス型はシグナルが厳選される代わりに反応が遅れがちです。

## 上位足トレンドの表示

上位足トレンドフィルターを有効にすると、チャート右上に現在の上位足トレンド(上昇/下降/横ばい)が
色付きで常時表示されます。上位足の時間足やEMA期間はパラメータから変更可能です
(3分足チャートの場合、上位足には5分より大きい足を選んでください。選択した足が現在のチャート足以下だと
右上に赤色で「上位足設定エラー」と表示されます)。

## 導入方法

1. TradingViewを開き、対象銘柄のチャートを3分足に設定する
2. 画面上部の「Pine Editor」を開く
3. `3min-scalping-indicator.pine` の中身を貼り付けて保存
4. 「チャートに追加」でインジケーターを表示
5. インジケーターの歯車アイコンから「表示するシグナル方式」を選び、各パラメータ(EMA期間、RSI水準、
   出来高倍率、必要条件数など)を調整
6. シグナルが出た足でアラートを鳴らしたい場合は、インジケーター上で右クリック→「アラートを追加」→
   条件で該当するシグナル([反発型]買い(順張り)発生、[EMA型]買いシグナル発生 など)を選択

## 注意事項

- 本インジケーターは売買を自動で行うものではなく、あくまで判断材料の一つです。
- 上位足トレンドフィルターは`request.security()`で取得した上位足の未確定足(現在形成中の足)を参照するため、
  リペイント(上位足が確定するまで表示が変わりうる)する場合があります。厳密なバックテストを行う場合は
  この点に留意してください。
- パラメータ(EMA期間・RSI水準・出来高倍率・上位足時間軸・ストキャスティクス設定)は銘柄のボラティリティに
  応じて調整してください。
- 投資判断は自己責任で行ってください。
