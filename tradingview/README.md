# 3分足デイトレ ゼロ遅延レベルシグナル

TradingView用のPine Script(v5)インジケーターです。3分足でのデイトレードを想定した
売買タイミング表示インジケーターです。

## 設計思想: 確定待ちを一切使わない

これまでの版はすべて「何かの確定を待ってから判定する」設計でした(ピボット高値/安値が
左右N本経過するまで確定しない、ローソク足パターンの完成を待つ、など)。これはデイトレの
「今この瞬間の値動きで判断したい」という要求と根本的に矛盾します。

このバージョンは、**確定を待つ必要が一切ない情報だけ**を使います。

| レベル | なぜ確定待ちが不要か |
|---|---|
| 本日のセッション高値/安値 | 今の値でその場で決まる。待ち時間ゼロ |
| 前日の高値/安値 | 前日の取引で既に確定済み。いつでも使える |
| VWAP | 元々セッション開始からの累積値。リアルタイム |

シグナルは「今確定した1本の足」を候補として拾い、**次の1本で継続したか**だけ追加確認します
(それ以上は待ちません)。1本だけで判定すると、ヒゲの単発反応(ノイズ)まで拾ってしまうため、
最小限の確認を挟んでいます。

- **反発(タッチ&リバース)**: その足がレベルにヒゲでタッチしたが、実体はレベルの反対側で
  終わった(節目で跳ね返った)候補足の後、次の足がさらに同じ方向に閉じたら採用
- **ブレイク(勢いで抜けた)**: その足がレベルを実体の強い足(レンジに対する実体の比率が
  一定以上)で突破した候補足の後、次の足がさらに同じ方向に閉じたら採用

以前の版のピボット確定(左右5本ずつ、実質10本以上のラグ)に比べると、追加の確認は1本分だけです。

## シグナルの見た目

| マーク | 意味 |
|---|---|
| ▲ 緑「反発買」 | サポート系レベル(本日安値/前日安値/VWAP)にタッチして反発 |
| ↑ ティール「抜け買」 | レジスタンス系レベル(本日高値/前日高値)を強い実体で上抜け |
| ▼ 赤「反発売」 | レジスタンス系レベルにタッチして反落 |
| ↓ マルーン「抜け売」 | サポート系レベルを強い実体で下抜け |

「節目での反発(タッチ&リバース)シグナルを使う」「節目のブレイク(勢いで抜けた)シグナルを
使う」を個別にON/OFFできるので、逆張り(反発)派・順張り(ブレイク)派どちらの好みにも
合わせられます。

## トレードプラン(損切り/利確ライン)

シグナルの的中率を上げることを目指すのではなく、シグナル発生時に次の2本の点線を同時に
表示して「当たったら何倍獲れて、外れたら何を失うか」を事前に見えるようにしています。

- **損切りライン(赤)**: シグナルの根拠になったレベルのすぐ外側。そのレベルが否定されたら
  撤退する、というライン
- **利確ライン(青)**: 反対側の直近レベル(本日高安→前日高安→VWAPの優先順で最初に見つかった
  もの)。使えるレベルがなければリスクの倍数(既定1.5倍)を目安として表示
- ラベルに損切り価格・利確価格・リスクリワード比率(RR)を表示

表示されるのは直近の買い/売りそれぞれ1件分のプランのみで、新しいシグナルが出ると前のものと
置き換わります。

## 設定項目

- **本日/前日の高値安値を使う・VWAPを使う**: 各レベルソースの個別ON/OFF
- **レベルをチャートに表示する**: レベルのライン表示ON/OFF
- **反発/ブレイクシグナルを使う**: シグナル種類の個別ON/OFF
- **ブレイク採用に必要な実体の強さ**: ブレイクシグナルにのみ適用。値が大きいほど、より
  勢いのある足だけを採用する
- **出来高フィルター**: 閑散相場でのだましを減らす任意フィルター
- **損切り/利確ラインを表示する**: トレードプラン(SL/TP)の表示ON/OFF
- **損切りをレベルからどれだけ離すか(ATRの倍率)**: 損切りラインとレベルの距離
- **次のレベルが使えない場合の利確目標**: 使えるレベルがない時の目標をリスクの何倍にするか
- **損切り/利確ラインを右に伸ばす本数**: プランのラインをチャート上に何本分表示するか

## 導入方法

1. TradingViewを開き、対象銘柄のチャートを3分足に設定する
2. 画面上部の「Pine Editor」を開く
3. 中身を全て削除してから `3min-scalping-indicator.pine` の内容を貼り付けて保存する
   (前のコードが残ったまま貼り足すとエラーの原因になります)
4. 「チャートに追加」でインジケーターを表示する
5. 歯車アイコンから各パラメータを調整する
6. シグナルが出た足でアラートを鳴らしたい場合は、インジケーター上で右クリック→
   「アラートを追加」→ 条件で「買いシグナル発生」または「売りシグナル発生」を選択

## 注意事項

- 本インジケーターは売買を自動で行うものではなく、あくまで判断材料の一つです。
- 前日の高値/安値は、チャートの銘柄・取引所のセッション区切りに基づいて計算されます。
  24時間取引される銘柄では「1日」の区切り方に注意してください。
- パラメータ(ATR倍率・出来高倍率・実体の強さなど)は銘柄のボラティリティに応じて
  調整してください。
- 投資判断は自己責任で行ってください。
